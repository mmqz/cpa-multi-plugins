# mimo

A [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) provider plugin for the Xiaomi MiMo family, serving its chat models through the platform OAuth lane, with desktop session adoption as a secondary lane.

Built with Go (CGO, c-shared). Release artifacts for all supported platforms are produced by CI from tagged commits — see the repository root README for the version matrix and the disclaimer.
