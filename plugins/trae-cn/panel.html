使用说明

1. 在 CPA Management 面板点击「登录」按钮触发 OAuth

2. 浏览器会打开 Trae CN 登录页面

3. 登录完成后回调本地端口，自动获取 token

4. Token 自动刷新（24h skew + 每天 03:00 全量）

5. 每天 09:00 自动签到领取积分

6. 多账号轮询（积分降序挑选 + 4 档 cooldown）

API 端点

Chat: POST /v1/chat/completions

Models: GET /v1/models

管理 API: /v0/management/plugins/trae-cn/*

已知限制

• DevicePublicKey 为空字符串（简化实现，未生成 ECDSA P-256 key pair）
