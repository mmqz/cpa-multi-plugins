# zcode

A [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) provider plugin for the GLM coding-plan family (Z.AI and BigModel). Both providers share one plugin; accounts are routed by the provider recorded in each auth file, and legacy single-file auth is adopted on startup.

Built with Go (CGO, c-shared). Release artifacts for all supported platforms are produced by CI from tagged commits — see the repository root README for the version matrix and the disclaimer.
