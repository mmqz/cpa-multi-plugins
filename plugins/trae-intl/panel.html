Trae Intl

插件信息

Provider: trae-intl

版本: v0.2.1

协议: Web SOLO remote (core-normal.trae.ai)

签到: Intl 无签到

Token 刷新: 已启用

使用说明

1. 在 CPA Management 面板点击「登录」触发 OAuth

2. 浏览器打开 Trae Intl 登录页（api.marscode.com）

3. 登录完成回调本地端口，自动获取 token

4. 支持 model: auto / work / 具体模型名

5. Web SOLO remote 协议（chat_sessions + events SSE）

API 端点

Chat: POST /v1/chat/completions

Models: GET /v1/models

管理 API: /v0/management/plugins/trae-intl/*
